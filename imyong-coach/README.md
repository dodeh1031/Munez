# 임용 2차 AI 코치 (imyong-coach)

심층면접(구상형·즉답형)·수업실연 연습 영상을 **브라우저에서 압축 → Gemini 멀티모달 분석 → 루브릭 리포트**로 보여 주는 로컬 실행용 웹 도구입니다.
별도 백엔드 서버·DB 없이 Next.js 하나로 동작합니다.

## 실행 방법

```bash
cd imyong-coach
npm install                 # postinstall이 ffmpeg.wasm 파일을 public/ffmpeg 로 복사
cp .env.example .env.local  # GEMINI_API_KEY 입력 (키 발급: https://aistudio.google.com/apikey)
npm run dev                 # http://localhost:3000 (이 컴퓨터에서만 접속 가능)
```

| 스크립트 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 — `127.0.0.1`에만 열려 같은 와이파이의 다른 기기에서는 접속할 수 없음 (API 키 보호) |
| `npm run build` / `npm start` | 프로덕션 빌드 / 실행 |
| `npm run lint` · `npm run typecheck` | 코드 검사 |

## 기술 스택

Next.js 16 (App Router, Turbopack) · React 19 · TypeScript · Tailwind CSS v4 · zustand(세션 상태) · zod(리포트 스키마) · `@ffmpeg/ffmpeg`(브라우저 압축) · `@google/genai`(Gemini File API · Structured Output) · lucide-react(아이콘)

## 영상 전처리 (브라우저 안에서만, 원본은 외부로 나가지 않음)

분석용 영상: **H.264 mp4 · 짧은 변 480px · 1fps · AAC 모노 16kHz** — 타임라인은 원본과 동일하게 유지됩니다.

| 경우 | 방식 | 15분 영상 소요(테스트 환경 기준) |
| --- | --- | --- |
| 브라우저가 재생 가능한 영상 (mp4·mov(H.264)·webm) | 브라우저로 1초마다 프레임 캡처 + ffmpeg.wasm 오디오 분리 동시 진행 → 인코딩 | 약 50초 |
| 브라우저가 재생 못하는 코덱 (예: Chrome의 아이폰 HEVC) | ffmpeg.wasm 호환 모드 변환 (참조되지 않는 프레임 디코딩 생략) | 약 3~4분 |

- Gemini는 영상을 초당 1프레임으로 샘플링하므로 1fps로 줄여도 분석 정보 손실이 없습니다.
- 비용은 파일 크기가 아니라 영상 길이·샘플링으로 결정됩니다. 압축은 업로드 시간을 줄이기 위한 것이고, 토큰 절감은 `GEMINI_MEDIA_RESOLUTION` 설정으로 합니다.
- 웹캠 녹화는 `localhost`(또는 https)에서만 동작합니다. 카메라는 탭을 바꾸거나 다른 페이지로 이동하면 자동으로 꺼집니다.

## Gemini 분석 설정 (`.env.local`)

| 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `GEMINI_API_KEY` | (필수) | 서버에서만 사용, 브라우저로 전달되지 않음 |
| `GEMINI_MODEL` | `gemini-4-argon` | 최신 Pro 모델(유료 전용). `gemini-2.5-pro`는 서비스 종료 중이라 새 키에서는 막힐 수 있음 |
| `GEMINI_THINKING_LEVEL` | (비움 = medium) | `low` / `medium` / `high` — 높을수록 깊이 따지지만 느리고 출력 토큰 증가 |
| `GEMINI_MEDIA_RESOLUTION` | `low` | 프레임당 토큰 low≈64 / medium≈256. 15분 영상은 low가 토큰을 약 1/3로 줄임 |
| `GEMINI_MOCK` | (비움) | `1`이면 API 호출 없이 샘플 리포트로 화면 흐름만 테스트 |
| `GEMINI_BASE_URL` | (비움) | 프록시·테스트 서버용. 보통 비워 둠 |

- 응답은 채점표에서 자동 생성한 JSON 스키마로 강제(Structured Output)하고, 받은 뒤 다시 검증합니다. 세부 기준이 하나라도 빠지면 오류로 처리합니다.
- 같은 영상·같은 문제로 다시 누르면 재분석하지 않고 리포트만 보여 줍니다(불필요한 비용 방지). 리포트의 **다시 분석**은 압축·업로드를 재사용하고 AI 분석만 새로 합니다.
- 리포트는 브라우저 메모리에만 있습니다. 보관하려면 **리포트 저장(JSON)** 을 누르세요.

## 시간 조건 (입력 화면 2단계)

- 수업실연: **실연 제한 시간** / 심층면접: **구상형 답변 시간**(구상형 문항 전체 합계)·**즉답형 답변 시간** / 공통: **시도교육청 조건 메모**
- AI에는 제한 시간과 코드로 잰 실제 영상 길이를 함께 전달하고, 초과하면 시간 관리 점수를 2점 이하로, 80% 미만이면 내용 부족 가능성을 지적하도록 지시합니다.
- 리포트 '종합' 탭의 **시간 관리** 카드는 AI와 별개로 사용 시간 vs 제한 시간을 계산해 보여 줍니다(면접은 문항별 소요 시간과 권장 시간 = 답변 시간 ÷ 문항 수).
- 마지막 입력값은 이 컴퓨터에 기억되고, 시간 조건만 바꿔도 다시 분석합니다. 기록에도 함께 저장됩니다.

## 말하기 지표 · 자기 채점 · 인쇄

- **말하기 탭**: AI가 수험생 발화를 들리는 그대로(군말 포함) 받아 적고, 프로그램이 그 기록으로 **말 속도(음절/분)**, **군말(음·어·그… 등) 횟수**, **말버릇 후보(이제·약간·그냥…)**, **3초 이상 멈춤**, **빨라진 구간**을 계산합니다. 발화 기록은 검색할 수 있고 타임스탬프로 영상 이동이 됩니다. (말 속도 참고 범위 240~320음절/분은 대략적인 값이며 `src/lib/speech.ts`에서 조정)
- **자기 채점 탭**: 같은 채점표로 1~5점을 매기면 AI 점수와 영역·세부 기준별로 비교합니다. 분석을 기다리는 동안 먼저 채점하면 AI 점수에 영향받지 않고 비교할 수 있습니다. 자기 채점은 기록에 함께 저장됩니다.
- **인쇄 · PDF**: 리포트 상단 버튼(또는 Ctrl+P). 모든 탭 내용을 한 문서로 정리해 인쇄하며, 인쇄 창에서 'PDF로 저장'을 고르면 PDF가 됩니다(파일 이름 예: `임용코치_수업실연_2026-11-17`). 발화 기록 포함 여부를 고를 수 있습니다.

## 분석 기록 (`/history`)

- 분석이 끝나면 리포트와 분석용 압축 영상(초당 1장)이 **이 브라우저(IndexedDB)** 에 자동 저장됩니다. 새로고침해도 남아 있습니다.
- 모드별 **종합 점수 변화 그래프**(회차별, 마우스·키보드로 값 확인, 점을 누르면 그 기록 열기)와 **영역별 변화**(첫 회 → 최근)를 보여 줍니다.
- 기록을 열면 리포트와 타임스탬프 이동을 다시 볼 수 있고, **원본 영상 연결**로 부드럽게 재생할 수 있습니다.
- 학교·집 컴퓨터 사이에는 **전체 백업 / 기록 불러오기(JSON)** 로 옮깁니다(영상은 포함되지 않음). 이미 있는 기록은 건너뜁니다.
- 브라우저의 사이트 데이터를 지우면 기록도 지워지므로 가끔 전체 백업을 권장합니다.

『끈기 임용 2차 초등특수』 심층면접·수업실연 채점 기준표를 요약·재구성했습니다.

| 모드 | 채점 영역 (세부 기준마다 1~5점) | 추가 평가 |
| --- | --- | --- |
| 수업실연 | 교사의 기본 자세(8) · 수업 운영 능력(5) · 특수교과의 수업(6) | 수업 조건별 반영 여부 |
| 심층면접 | 교직 적성 · 교직관 · 인격 및 소양 · 의사소통 능력 · 학습지도 능력 · 태도·전달력 | 문항별 평가(개념 이해·문제 분석·해결 방안·의지 + 문제 유형 type 1~10), 자기점검표 |

- 영역 점수 = 세부 기준 평균, 종합 점수 = 영역 평균 ÷ 5 × 100 (코드에서 계산)
- `src/lib/rubrics/*.ts`의 기준을 고치면 화면과 AI 응답 스키마가 함께 바뀝니다.
